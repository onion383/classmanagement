# 前端组件（`src/components/`）

本文件汇总 `src/components/` 下全部组件，按子目录分节。约定：`被谁使用` 一列基于源码中出现的使用处整理；懒加载（`defineAsyncComponent` / `import()` + `v-preload`）的页面同样计入。`props / emits` 列为关键契约，非穷尽。

## 1. `components/layout/`

| 文件 | 职责 | 关键 props / emits | 被谁使用 |
| --- | --- | --- | --- |
| `Sidebar.vue` | 侧边栏导航。按 `navGroups` 分组（概览 / 基础信息 / 核心管理 / 活动中心 / 系统管理）渲染 `router-link`；图标随主题 `iconStyle` 在 lucide 与 emoji 间切换；按下即乐观高亮（`pendingPath`）；悬停 `prefetchRoute` 预取路由 chunk | 无 props / emits（读取 `router`、`route` 与主题 store） | `App.vue` |

**核心机制说明（Sidebar）**：`router-link` 的 `active-class` 需等导航 resolve（懒加载挂载 + 数据请求）后才生效，大页面上会有「点了没反应」的观感，因此该组件自行判定选中态：`pointerdown` 时记录 `pendingPath` 保证同时仅一个高亮，路由真正切换后（`watch` `route.path`）交回 `route.path`。图标样式通过 `storeToRefs(useThemeStore()).iconStyle` 决定。`

## 2. `components/tables/`

| 文件 | 职责 | 关键 props / emits | 被谁使用 |
| --- | --- | --- | --- |
| `DynamicTable.vue` | 动态列 CRUD 表格。列头排序/搜索、单元格双击编辑、行内新增行、多选、行列拖拽（交换/移动）、底部「点击添加一行」；内置行增删的过渡动画与列宽快照逻辑；文件内另定义一个 `TransitionGroup` 包装子组件（props `name/tag/dataRows`，emits `enter/afterEnter/leave/afterLeave`） | props：`fields`(必填)、`rows`(必填)、`newRow`、`sortField`、`sortOrder`、`editingCell`、`maxRows`、`hideSelectAll`、`hideMoveButtons`、`hideAddRow` 等；emits：`contextmenu`、`search`、`toggleSort`、`saveNewRow`、`cancelNewRow`、`startEdit`、`saveCell`、`moveRow`、`deleteRow`、`addNewRowAtBottom`、`updateNewRow`、`manageReceipt`、`swapRows`、`swapColumns`、`moveSelectedRows`、`selectionChange` | `ClassroomView`、`FeeManagement`、`LeaveManagement`、`ScoreManagement`、`ImportExcel`、`DeduplicateDialog` |
| `GridView.vue` | 网格表（座位 / 课表 / 值日）。单元格选择（拖选 / 长按）、单元格双击编辑、候选下拉（`Teleport` + fixed 定位，与座位表一致）、行列拖拽交换、行元信息编辑 | props：`colHeaders`(必填)、`rows`(必填)、`showPeriodColumn`、`title`、`hideMetaColumns`、`showRowNumber`、`enableCandidate`、`candidateItems`、`candidateExcludeIds`、`candidateLabelField`、`minTableHeight`、`rowHeaderLabel` 等；emits：`update:cells`、`swapRows`、`swapColumns`、`update:row-meta`、`cell-dblclick` | `SeatView`、`ScheduleView`、`DutyView`、`DutyArrangementDialog`、`SmartArrangementDialog` |
| `InlineStudentEditor.vue` | 行内学生/候选项编辑器（浮层输入 + 候选列表 + 高亮选择 + 排除已选） | props：`visible`、`position`、`items`、`excludeIds` 等；emits：`select`、`cancel` | 当前源码中未见引用处（可能为遗留/待接入，待确认） |

**核心机制说明（DynamicTable）**：它是 `useTableCRUD` 的纯展示层，把状态（`rows/fields/editingCell/sortField/...`）与数据操作全部上抛给宿主页/组合式函数处理，自身只维护表格交互细节（编辑中单元格、多选、拖拽、列宽快照）。因此所有接口调用（增列、改列、移动、导入等）实际发生在 `useTableCRUD` 中，而非组件内。

**核心机制说明（GridView）**：同样是受控组件，通过 `update:cells` / `swapRows` / `swapColumns` / `update:row-meta` / `cell-dblclick` 把单元格与行列操作上抛，宿主（如 `useSeatGrid` / 各视图）负责落库与撤销记录。其候选下拉采用 `Teleport` 到 body + `position: fixed` 的定位方案，避免被父容器 `overflow` 裁剪。
