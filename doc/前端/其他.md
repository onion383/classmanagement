| `dateTime.js` | 日期格式化公共工具：统一各弹窗/视图里各自复制的「补零 + 拼日期串」逻辑 | `pad2(n)`、`formatDate(d)`、`formatDateTime(d)`、`formatDateTimeLocal(d)` | 各弹窗（AddScore/AddLeave/AddActivity/AddCountdown）与视图（DashboardView/ScoreManagement/LeaveManagement/SettingsView/AlbumView）、`AnimatedClock.vue`、`subwindows/widget/Timer.vue` |

| `dialogPrefetch.js` | 注册 `v-preload` 指令：`mouseenter` 时 80ms 防抖后加载传入的 loader（弹窗预取） | 默认导出：`vPreload` 指令对象 | `main.js` 全局注册；各视图按钮上使用 `v-preload="loader"` |
| `dialogOverlayPulse.js` | 事件委托：点击「弹窗遮罩」（`class` 含 `inset-0` 且 `bg-black/`，且直接子元素含 `.dialog-card`）时弹出「请关闭弹窗」提示 | `initDialogOverlayPulse()` | `main.js` |
| `routePrefetch.js` | 悬停预取目标视图 chunk：`mouseenter` 时 80ms 防抖后调用目标路由的懒加载函数 | `prefetchRoute(router, rawPath)` | `Sidebar.vue`（导航项 `pointerover`） |
| `collator.js` | 中文排序比较器（统一复用，避免每次调用重建）：`localeCompare` 每次调用都要新建 Collator，而排序比较器会被调用 O(n log n) 次，实测 1000 条排序快 2.6 倍 | `zhCollator`（`Intl.Collator('zh')`）、`naturalCollator`（`Intl.Collator('zh-Hans-CN', { numeric, sensitivity:'base' })`，用于文件名自然排序） | `composables/useTableCRUD.js`（表头排序）、`tables/DynamicTable/DynamicTable.vue`（列筛选下拉）、`components/import-export/ExportAlbumIndex.builder.js`、`views/LeaveManagement.vue`、`views/ScoreManagement.vue`、`components/base/LeaveTimeline.vue` |
| `pdfFont.js` | PDF 导出的中文字体：全量字体加载一次并缓存（gzip 魔数判断后解压），按本次要绘制的字符做动态子集；子集失败**退回全量字体**，保证导出不出错 | `loadPdfFontBase64(text)`、`collectPdfText(...parts)` | `composables/exportFormats.js`、`components/import-export/ExportExcel/ExportExcel.exporters.js` |
| `hbSubset.js` | harfbuzz wasm 字体子集引擎：把全量 TTF 裁成只含指定字符的子集。**缓存编译产物 Module、不缓存 Instance** —— wasm 线性内存初始化即 65MB，实例可被 GC 回收但「只要有一个 export 函数可达就整块存活」，所以每次导出新建实例、用完即弃（实测 external 零增长，每次多 5~12ms） | `subsetTtf(fontBytes, text)`、`subsetWithExports(hb, fontBytes, text)`（供 Node 探针直接调用） | `utils/pdfFont.js` |

## 5. 指令

- `v-preload`：定义于 `utils/dialogPrefetch.js`，在 `main.js` 中全局注册。用法 `v-preload="loadXxxDialog"`，悬停按钮时预取对应弹窗 chunk，配合 `defineAsyncComponent` 实现「点开时无加载等待」。
- 弹窗遮罩脉冲（`initDialogOverlayPulse`）：非 Vue 指令，而是 `main.js` 启动时注册的全局事件委托（见上表 `dialogOverlayPulse.js`）。

## 9. 代码检查（ESLint）

`npm run lint`（根目录，一次跑完三块）→ `eslint student-frontend/src student-backend electron`。

**定位：只做「低级错误护栏」，不做风格管理。** 刻意**不启用** `eslint:recommended` 与 vue 的规则集——后者大量是审美类（如 `vue/multi-word-component-names`），对本项目没有价值，只会淹没真正的问题。实测严格档会报 362 条、其中 73% 是 `no-unused-vars`（且多为 `catch (_)` 占位噪音），最小档只报 64 条且能抓到真 bug。

配置在**根目录 `eslint.config.mjs`**（不是各包各一份，避免规则漂移）。文件名用 `.mjs` 是因为根 `package.json` 是 CJS，`.js` 会被按 CJS 解析而无法 `import` 这些 ESM 插件。三块代码运行环境不同、规则相同：

| 范围 | 模块系统 | 全局 |
| --- | --- | --- |
| `student-frontend/src` | ESM | `browser` + Vue 编译器宏（`defineProps` 等） |
| `student-backend`、`electron` | CJS | `node` |
| `electron/preload.js` | CJS | `browser` + `node`（跑在渲染进程里） |

规则分两档：

| 档位 | 规则 | 说明 |
| --- | --- | --- |
| **error** | `no-undef`、`no-dupe-keys`、`no-dupe-args`、`no-unreachable`、`no-cond-assign`、`no-self-assign`、`no-fallthrough`、`no-async-promise-executor`、`no-constant-condition` | 命中基本就是 bug，必须修 |
| **warn** | `no-empty`（放行空 catch）、`eqeqeq`、`no-unused-vars`（忽略 `^_` 与 catch 参数）、`no-prototype-builtins` | 提示性，不阻塞任何流程 |

三件刻意不做的事：

1. **不挂进 `npm run build`**——lint 失败不该挡住打包，尤其是历史告警没清完时。
2. **不扫 `testjs/`**——探针脚本故意有内联调试代码和临时 `node -e` 风格，纳入只会产生噪音。
3. **不加格式化类规则**——项目现有写法是自洽的，强加风格只会制造 diff 噪音。

当前基线：**0 problem**。接入时它抓到 3 个人工通读漏掉的真 bug：`useTableCRUD.js` 调用了未定义的 `notifySuccess`（导致导入成功后提示「导入失败」且表格不刷新）、`LeaveManagement.vue` 的 `data()` 里 `leaveTypeOptions` 重复定义、`ai.conversations.js` 里 `ask` 未声明（写成隐式全局，并发请求会互相覆盖）。

> 清理时的一个教训：`no-unused-vars` 要逐条看变量名。`main.desktop-layer.js` 的 `koffi.struct('POINT')` 看似未使用，实际是**按名字注册类型**，被 `user32.func('... RECT *lpRect')` 字符串引用着；`main.js` 的 `detectFirstRun` 是没接线的首启判定（保留了意图说明）。
