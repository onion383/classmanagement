# 其他前端模块（stores / router / styles / utils / 指令 / 独立窗口 / 静态资源）

## 1. 状态管理（`src/stores/`）

| 文件 | 职责 | 关键内容 | 被谁使用 |
| --- | --- | --- | --- |
| `theme.js` | 唯一 Pinia store（`defineStore` setup 风格）。主题状态与外观应用 | `PRESETS`：`base`、`glass`、`glass2`、`win11`、`minimal`；状态：`currentTheme`、`customColors`、`customThemes`、`backgroundImage`、`bgMaskOpacity`、`glassOpacity`、`iconStyle`、`topbarColor`、`animationsEnabled`；`applyTheme()` 写入 `data-theme`、`data-topbar-color`、`no-animations` class、CSS 变量与背景图（glass 用内置 `DEFAULT_GLASS_BG=/glass-bg-opt.jpg`），并发 `theme-chrome` IPC 通知主进程 | `App.vue`、`Sidebar.vue`、`IconGlyph.vue`、`main.js` 及各入口 `main.js`、设置页 |

## 2. 路由（`src/router/`）

| 文件 | 职责 | 关键内容 | 被谁使用 |
| --- | --- | --- | --- |
| `index.js` | 路由表与全局守卫 | 16 条路由 + `/account → /settings` 重定向；PROD 用 `createWebHashHistory`，dev 用 `createWebHistory`；`beforeEach` 校验 JWT `exp`、未登录跳 `/login`、首次导航后台校验 `/api/me`、进首页 `ensureDashboardData()`；导出 `prefetchRoutes()` 空闲逐条预热懒加载路由 chunk | `main.js`（`app.use(router)`）、`App.vue`（`router-view`）、`Sidebar.vue` |

## 3. 样式（`src/styles/`）

| 文件 | 主题 / 作用 |
| --- | --- |
| `index.css` | 样式入口。导入 Tailwind 与各主题文件；全局禁止文本选中（`user-select:none`，输入类元素例外）；用 `@theme` 注册主题令牌；`sortablejs` 拖拽样式；复选框描画动画；`html.no-animations` 全局动画总开关；`main` 字体栈与班干部树滚动条处理 |
| `theme-base.css` | 基础主题（默认）。定义 `:root` 全部 CSS 变量（绿主色 `#22c55e`、深色侧边栏）；`data-theme="base"` 下透视亚克力的浅灰半透明 `main` 与标题栏 |
| `theme-glass.css` | 毛玻璃主题 v3（`data-theme="glass"` 与 `win11` 共用组件样式）。蓝灰底 + 白色玻璃变量、荧光描边按钮、弥散光斑背景、玻璃标题栏；含 `GridView` 网状表格毛玻璃等覆盖；注释说明需配 `data-topbar-color` 切换标题栏配色 |
| `theme-glass2.css` | 新毛玻璃主题「薰衣草冷雾」（`data-theme="glass2"`）。长春花蓝强调色、柔光斑背景、分层柔和阴影；仅对大面板做模糊；透明度由 `--glass-opacity` 驱动并 +0.15 偏移 |
| `theme-win11.css` | Win11 主题（`data-theme="win11"`）。组件样式复用 glass，仅页面背景完全透明以透出窗外亚克力；登录页与标题栏作透明覆盖 |
| `theme-minimal.css` | 极简主题（`data-theme="minimal"`）。纯白背景、无阴影、圆角为 0；`main` 为半透明白磨砂 |
| `dialog-transition.css` | 弹窗通用过渡动画。约定 `<Transition name="dialog">` + `class="dialog-card"`；打开为遮罩淡入 + 卡片 96%→101.5%→100% 回弹缩放，关闭 100%→97% 淡出；刻意不逐帧过渡 `backdrop-filter` |
| `select.css` | 自定义下拉框（`AppSelect`）全局样式，类名前缀 `.av-select`；含 glass/win11 的毛玻璃覆盖与聚焦描边 |
| `utilities.css` | 主题相关工具类与 `@utility`：`skeleton-block` 骨架屏、`glass`、`transition-theme`、`content-visibility-auto`；以及「基础/极简主题下弹窗遮罩改用背景模糊」的规则 |
| `buttons-old.css` | 旧版彩色玻璃按钮样式备份。默认**不启用**（未在入口引入），保留用于回退 |

## 4. 工具（`src/utils/`）

| 文件 | 职责 | 关键导出 | 被谁使用 |
| --- | --- | --- | --- |
| `apiUrl.js` | 生产模式以 `file://` 运行时，`/api/...` 会解析到磁盘根导致 404，统一补后端地址；并为 `img`/背景图追加鉴权 token | `apiUrl(path)`、`resourceUrl(path)` | 各视图（图片/收据/缩略图显示处） |
| `httpClient.js` | 各窗口入口共用的 axios 装配：设置 baseURL、注入登录 Token、后端未就绪时退避重试、挂载安全通道加密。收敛原先在 setup/widget/desktop-widget 各入口重复的同一段逻辑 | `setupApiClient({ baseURL, getToken })`、`backendBaseUrl()` | `subwindows/setup/main.js`、`subwindows/widget/main.js`、`subwindows/desktop-widget/main.js`（`main.js` 因另有 401 去重等逻辑暂未接入） |
| `dateTime.js` | 日期格式化公共工具：统一各弹窗/视图里各自复制的「补零 + 拼日期串」逻辑 | `pad2(n)`、`formatDate(d)`、`formatDateTime(d)`、`formatDateTimeLocal(d)` | 各弹窗（AddScore/AddLeave/AddActivity/AddCountdown）与视图（DashboardView/ScoreManagement/LeaveManagement/SettingsView/AlbumView）、`AnimatedClock.vue`、`subwindows/widget/Timer.vue` |
| `backendReady.js` | 后端就绪等待与查询。订阅主进程 `backend-ready` 事件，暴露 `backend-status` 查询兜底竞态 | `waitForBackendReady(timeoutMs = 4000)`、`isBackendReady()` | `utils/httpClient.js`（各窗口入口的响应拦截器重试）、`main.js` |
| `dialogPrefetch.js` | 注册 `v-preload` 指令：`mouseenter` 时 80ms 防抖后加载传入的 loader（弹窗预取） | 默认导出：`vPreload` 指令对象 | `main.js` 全局注册；各视图按钮上使用 `v-preload="loader"` |
| `dialogOverlayPulse.js` | 事件委托：点击「弹窗遮罩」（`class` 含 `inset-0` 且 `bg-black/`，且直接子元素含 `.dialog-card`）时弹出「请关闭弹窗」提示 | `initDialogOverlayPulse()` | `main.js` |
| `routePrefetch.js` | 悬停预取目标视图 chunk：`mouseenter` 时 80ms 防抖后调用目标路由的懒加载函数 | `prefetchRoute(router, rawPath)` | `Sidebar.vue`（导航项 `pointerover`） |

## 5. 指令

- `v-preload`：定义于 `utils/dialogPrefetch.js`，在 `main.js` 中全局注册。用法 `v-preload="loadXxxDialog"`，悬停按钮时预取对应弹窗 chunk，配合 `defineAsyncComponent` 实现「点开时无加载等待」。
- 弹窗遮罩脉冲（`initDialogOverlayPulse`）：非 Vue 指令，而是 `main.js` 启动时注册的全局事件委托（见上表 `dialogOverlayPulse.js`）。
