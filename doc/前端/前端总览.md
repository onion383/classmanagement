# 班集 · 前端层（student-frontend）开发文档

本组文档描述「班集」桌面应用前端层 `student-frontend/` 的结构与逐文件职责。前端是运行在 Electron 渲染进程中的 Vue 3 单页应用，通过 HTTP 与 `student-backend/`（Express，默认 `http://localhost:3000`）通信。

## 1. 定位与职责

- 提供班级管理全部界面：学生、分组、课程表、座位、值日、加分、请假、班费、相册、活动、AI 助手、系统设置、关于。
- 承载多个独立窗口入口：主窗口、首次引导（setup）、数据库迁移（migration）、工具箱浮窗（widget）、桌面小组件（desktop-widget）。
- 负责窗口外观（无边框自绘标题栏 / 主题 / 背景图 / 透明度）、登录态维护、后端就绪等待、请求加密（安全通道）、撤销重做、懒加载与预取等前端侧机制。

## 2. 技术栈

| 其他 | exceljs、xlsx、jspdf、html2canvas、sortablejs、dompurify、marked |

## 3. 入口与构建

### 3.1 多页面入口（`vite.config.js` 的 `rollupOptions.input`）

| HTML | 挂载点 | 入口 JS | 顶层组件 | 用途 |
| --- | --- | --- | --- | --- |
| `index.html` | `#app` | `src/main.js` | `src/App.vue` | 主窗口 |
| `setup.html` | `#setup-app` | `src/setup/main.js` | `src/setup/Setup.vue` | 首次安装引导 |
| `migration.html` | `#migration-app` | `src/migration/main.js` | `src/migration/Migration.vue` | 数据库迁移窗口 |
| `widget.html` | `#widget-app` | `src/widget/main.js` | `src/widget/WidgetApp.vue` | 工具箱浮窗 |
| `desktop-widget.html` | `#desktop-widget-app` | `src/desktop-widget/main.js` | `src/desktop-widget/DesktopWidget.vue` | 桌面小组件 |

- `index.html` 内含首屏 splash 占位（避免白屏）与启动失败兜底 UI，`<script type="module" src="/src/main.js">`；注释明确不手写 `modulepreload`。
- `setup.html` / `migration.html` / `widget.html` / `desktop-widget.html` 各自挂载到不同根节点并加载对应 `main.js`。

### 3.2 `src/main.js`（主窗口入口，核心机制）

- 生产模式下设置 `axios.baseURL = 'http://localhost:3000'`；请求拦截器注入 `Bearer token`。
- 401 去重提示并跳转登录页。
- 响应拦截器对「无 response 的网络错误」配合 `waitForBackendReady` 重试（最多 6 次）；重连期间写请求不自动重发，避免重复写。
- 调用 `setupSecureAxios` 装配安全通道加密。
- Vue 初始化前先写入主题 CSS 变量，避免首屏闪烁；预加载落地页组件。
- 全局注册 `IconGlyph`；调用 `initDialogOverlayPulse`；转发原生右键菜单 IPC；注册 `v-preload` 指令。
- splash 占位保活至「backend-ready + 路由就绪 + 样式就绪」；启动失败时提供「重启后端 / 退出」兜底。
- 说明：`useElasticScroll` 的 `startElasticScroll()` 在当前版本被注释停用（见 `composables.md`）。

### 3.3 `src/App.vue`（根组件，核心机制）

- 自绘无边框标题栏：最小化 / 最大化切换 / 关闭按钮（`win-minimize`、`win-maximize-toggle`、`win-close`）。
- 登录页全屏无侧边栏；其余页面为 `Sidebar` + `router-view`，并用 `<KeepAlive :max="16">` 缓存页面。
- 挂载 `NotificationToast`；后端运行期异常时显示全屏遮罩。
- 引入 `ShutdownMenuDialog` 作为关闭选择弹窗。
- 提供 AI 助手悬浮按钮与可拖动浮窗（异步组件 `AiAssistant`）。
- `mounted` 中通过 `requestIdleCallback` 双重空闲后调用 `reportWidgetsReady` 与 `prefetchRoutes`。

### 3.4 Vite 配置

| 文件 | 说明 |
| --- | --- |
| `vite.config.js` | plugins：`vue()`、`tailwindcss()`、自研 `nonBlockingCss()`（`closeBundle` 把构建产物 CSS link 改为 `media="print" onload` 切回 `all`，实现非阻塞加载）；`server.warmup` 预编译首屏模块；代理 `/api` 与 `/uploads` 到 `localhost:3000`；`base:'./'`；`modulePreload.polyfill:false`；五个入口 |
| `vite.perf.config.js` | 性能测量专用配置；`PERF_TARGET=dist` 时用 `preview`，端口默认 5174/5175，代理到 3100 |
| `resize-bg.mjs` | 用 `sharp` 把 `public/glass-bg.jpg` 压缩为长边 2560px 的 `public/glass-bg-opt.jpg`（毛玻璃主题背景） |

### 3.5 Tailwind 与主题变量

- `src/styles/index.css` 通过 `@import "tailwindcss"` 引入 Tailwind，并用 `@theme` 把 CSS 变量注册为 Tailwind 可用的 `--color-* / --shadow-* / --radius-*` 令牌。
- 主题切换以根元素 `data-theme` 属性驱动，各主题在 `assets/theme-*.css` 中覆盖同名 CSS 变量。

**核心机制说明（router）**：`beforeEach` 守卫在本地校验 JWT 的 `exp`（解码失败视为未过期，由后端 401 兜底）；无 token 时统一跳 `/login`。首次导航时后台非阻塞地请求一次 `/api/me`，token 被后端作废时由响应拦截器统一处理 401。进入首页时调用 `ensureDashboardData()` 并发拉取看板数据。导出的 `prefetchRoutes()` 会在空闲时「逐条 + 让出空闲」地预热所有懒加载路由 chunk，避免点击侧边栏时等待下载/解析。

## 6. 主题系统

主题由 `stores/theme.js` 的 `PRESETS` 定义，共 5 套：`base`、`glass`、`glass2`、`win11`、`minimal`。同时支持自定义主题、自定义颜色、背景图、背景遮罩透明度、玻璃透明度、图标样式（`color` 线性图标 / `emoji` 表情）、标题栏配色（`blue` / `light`）与动画总开关。`applyTheme()` 会写入 `data-theme`、`data-topbar-color`、`no-animations` class、CSS 变量与背景图，并通过 `theme-chrome` IPC 通知主进程调整窗口外观。

| 主题 | 变量文件 | 特征 |
| --- | --- | --- |
| base | `styles/theme-base.css` | 默认浅色、绿色主色 `#22c55e`、深色侧边栏 |
| glass | `styles/theme-glass.css` | 蓝灰底、白玻璃、荧光描边按钮，可用内置背景图 |
| glass2 | `styles/theme-glass2.css` | 薰衣草/长春花底色、柔光斑背景、更厚高光玻璃（透明度由 `--glass-opacity` 驱动并 +0.15 偏移） |
| win11 | `styles/theme-win11.css` | 复用 glass 全套组件样式，仅页面背景透明，由窗外亚克力透出桌面 |
| minimal | `styles/theme-minimal.css` | 纯白、无阴影、直角（圆角为 0） |

## 7. 关键前端机制（概要）

- **安全通道**：`composables/secureChannel.js` + `composables/secureAxios.js`，基于 ECDH P-256 + HKDF(`campus-secure-v1`) + AES-256-GCM，由 `VITE_SECURE` / `window.__SECURE_CHANNEL__` 开关控制。
- **后端就绪等待**：`utils/backendReady.js` 订阅主进程 `backend-ready`，并提供 `backend-status` 查询兜底竞态。
- **懒加载与预取**：弹窗异步加载 + `v-preload` 指令（悬停 80ms 防抖预取）+ `routePrefetch` 悬停预取路由 chunk + `KeepAlive(max 16)`。
- **表格体系**：`DynamicTable`（动态列 CRUD 表）与 `GridView`（座位/课表/值日网格）。
- **撤销/重做**：`composables/useUndo.js` 把操作持久化到后端 `/api/undo`，支持 `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y`。
