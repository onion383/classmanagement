## 核心页面机制说明

- **DashboardView**：作为首屏，其数据由 `composables/useDashboardData.js` 的 `ensureDashboardData()` 统一并行拉取（schedule/duty/countdowns/leaves/students/scores/activities/fee-records/album 共 9 个接口）并做模块级缓存，避免与路由懒加载串行等待。班级信息大框可编辑，写回 `widget-settings/class-info`。
- **ClassroomView / SeatView / ScheduleView / DutyView / LeaveManagement / FeeManagement / ScoreManagement**：共同构成「表格 / 网格」两大类交互页。学生信息与班费页走 `useTableCRUD` + `DynamicTable`（动态列 CRUD）；座位、课表、值日走 `useSeatGrid` / 自研网格逻辑 + `GridView`（网格、座位、课表、值日）。
- **Login.vue**：覆盖了安装后首次进入、常规登录、离线恢复、找回密码等多条路径，是全应用唯一不显示侧边栏的全屏页面。
