# 班集 · 小组件文档

本文覆盖「班集」的两个独立窗口入口子系统——**工具箱浮窗**（`widget`）与**桌面小组件**（`desktop-widget`），跨渲染层（`student-frontend/src/widget`、`src/desktop-widget`）与主进程（`electron/main/widget.js`）。

此前这部分内容附在前端文档的「浮窗与独立窗口」小节，现独立成文；前端其余内容见 [前端/前端总览.md](./前端/前端总览.md) 与 [前端/其他.md](./前端/其他.md)，主进程侧完整说明见 [主进程/主进程.md](./主进程/主进程.md)。

## 一、构成

两者都是「独立 HTML 入口 + 独立顶层组件」的独立渲染窗口，由主进程单独创建：

| 子系统 | HTML 入口 | 入口 JS | 顶层组件 | 用途 |
| --- | --- | --- | --- | --- |
| 工具箱浮窗 | `widget.html` | `src/widget/main.js` | `src/widget/WidgetApp.vue` | 悬浮工具箱：正/倒计时、点名、屏幕注释、一键截屏 |
| 桌面小组件 | `desktop-widget.html` | `src/desktop-widget/main.js` | `src/desktop-widget/DesktopWidget.vue` | 桌面常驻信息面板：时钟、倒计时、下节课、课程、值日与人数 |

两者均在 `vite.config.js` 的 `rollupOptions.input` 中登记；主进程 `electron/main/widget.js` 负责窗口创建与生命周期。

## 二、工具箱浮窗（`src/widget/`）

| 文件 | 职责 | 关键点 |
| --- | --- | --- |
| `widget/main.js` | 工具箱浮窗入口 | `axios.baseURL` 固定 `localhost:3000` + token 拦截 + 重试 + `setupSecureAxios`；`applyTheme()` 后挂载 `#widget-app` |
| `widget/WidgetApp.vue` | 工具箱主界面：悬浮图标（左键展开菜单，右键呼出退出菜单）、功能菜单网格、可拖动 | 状态 `tool`/`menu`/… 切换；从 `GET /api/widget-settings` 读取启用配置 |
| `widget/Timer.vue` | 工具箱·正计时 / 倒计时 | 仅前端计时 |
| `widget/RollCall.vue` | 工具箱·点名器 | `GET /api/students` 取名单后随机点名 |
| `widget/Note.vue` | 工具箱·屏幕注释（截图标注） | 读 `GET /api/widget-settings`；使用 `ColorSwatch` |
| `widget/Screenshot.vue` | 工具箱·一键截屏 | 读 `GET /api/widget-settings` |

## 三、桌面小组件（`src/desktop-widget/`）

| 文件 | 职责 | 关键点 |
| --- | --- | --- |
| `desktop-widget/main.js` | 桌面小组件入口 | token 通过 IPC `get-main-token` 获取（回退 `localStorage`）；`setupSecureAxios` 后挂载 `#desktop-widget-app` |
| `desktop-widget/DesktopWidget.vue` | 桌面小组件界面：时钟（`AnimatedClock`）、最近倒计时、下一节课、左栏课程、右栏今日值日与人数情况 | `GET/PUT /api/widget-settings/apps`；`GET /api/schedule`、`/api/duty`、`/api/countdowns`、`/api/leaves`、`/api/students`（失败时降级为空数据） |

## 四、主进程侧（`electron/main/widget.js`）

窗口生命周期与 IPC 全部集中在 `electron/main/widget.js`（导出 `registerWidgetIpc`、`createWidgetWindow`、`hideWidgetWindow`、`showWidgetWindow`、`createDesktopWidgetWindow`、`getWidgetWindow`、`getDesktopWidgetWindow`、`setDesktopWidgetWindow`、`isDesktopEnabled`）。

**工具箱浮窗**：

- 窗口属性：`frame:false + transparent:true`、`alwaysOnTop`、`skipTaskbar`、不可缩放。
- 尺寸为「视觉内容 + 2×`WIDGET_SHADOW_MARGIN`(16px)」，用于绘制阴影。
- **会话级显隐采用「隐藏即 `destroy`」**（而非仅 `hide`），以释放整个渲染进程；重启用 `lastWidgetBounds` 复原位置。

**桌面小组件**：

- 宽 320、高度约屏幕 95%，无边框 + 亚克力（`transparent:false`）、不置顶、不可缩放。
- 由 `setDesktopEnabled` / `scheduleCreateDesktop` 按启用状态创建/关闭；主窗口首帧空闲回报 `widgets-ready` 时创建工具箱并按启用状态建关桌面组件。

**主要 IPC 通道**（均需在 [preload.js](../electron/preload.js) 白名单登记）：

- `on`：`widgets-ready`、`desktop-widget-enabled`、`widget-resize`、`widget-move-to`、`widget-center`、`widget-restore-position`、`widget-fullscreen`、`widget-restore`、`widget-set-ignore-mouse`、`widget-set-visible`、`widget-drag-start/move/end`、`widget-context-menu`、`widget-set-session-visible`、`to-widget`、`to-main`
- `handle`：`get-session-widget-visible`、`get-main-token`

## 五、数据接口

| 接口 | 用途 |
| --- | --- |
| `GET / PUT /api/widget-settings` | 工具箱启用配置、常用软件列表、首页班级信息（另有 `GET/PUT /apps`、`GET/PUT /class-info`） |
| `GET /api/students` | 点名器取名单、桌面组件人数统计 |
| `GET /api/schedule`、`/api/duty`、`/api/countdowns`、`/api/leaves` | 桌面小组件信息面板数据 |

## 六、约定与注意

- **IPC 白名单**：新增小组件相关通道必须同步加入 `electron/preload.js` 的白名单，否则前端调用会被静默拒绝或 `Promise.reject`。
- **主题一致性**：两个入口都先在 `main.js` 中 `applyTheme()`、再挂载顶层组件，保证浮窗/桌组件外观跟随当前主题。
- **token 来源差异**：工具箱浮窗走常规登录态；桌面小组件因无登录界面，token 通过 IPC `get-main-token` 向主进程索取（回退 `localStorage`）。
- **多窗口并存**：工具箱浮窗与桌面小组件可同时存在，但同一时刻各自至多一个实例；重建前需先销毁旧窗口。
